# 🌐 Personal Portfolio Website

This is my personal portfolio website built using HTML, CSS, and JavaScript. It showcases my projects, skills, and background as a Computer Science (AI/ML) student.

---

## 🚀 Features

- Responsive and clean UI design  
- Typewriter animation in the header  
- Smooth scrolling navigation  
- Sections for About, Projects, Skills, Education, and Contact  
- Links to GitHub projects and demos  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## 📂 Project Structure

- portfolio.html – Main structure of the website  
- style.css – Styling and layout  
- script.js – Interactivity (typewriter effect, smooth scroll)  

---

## ▶️ How to Run (Locally)

### Method 1: Open directly
1. Download or clone the repository  
2. Open `portfolio.html` in your browser  

---

### Method 2: Using Terminal

#### On Windows:
start portfolio.html

#### On Mac:
open portfolio.html

---

### Method 3: Using Live Server (Recommended)

1. Open the project folder in VS Code  
2. Install the Live Server extension  
3. Right-click `portfolio.html`  
4. Click "Open with Live Server"
